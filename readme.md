# Novix

**A desktop chat app for running language models locally.**

Novix lets you download a model, chat with it on your own computer, and keep your conversation history locally.

## Features

- Chat with locally run language models.
- Browse model options and recommendations for your computer.
- Monitor, pause, resume, or cancel model downloads.
- Save, rename, and revisit conversations.
- Attach images when using a model that supports vision.
